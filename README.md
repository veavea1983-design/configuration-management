# Эмулятор командной оболочки UNIX

Практическая работа №1 по дисциплине «Конфигурационное управление»

**Вариант:** 3  
**Язык программирования:** Python 3  
**Реализованы этапы:** 1 — REPL, 2 — Конфигурация

## 1. Описание проекта

Программа представляет собой эмулятор командной оболочки UNIX-подобной операционной системы.

На первом этапе реализован интерактивный консольный интерфейс (CLI), позволяющий вводить команды, обрабатывать аргументы и получать результаты выполнения.

Программа использует реальные данные операционной системы для формирования приглашения к вводу.

## 2. Реализованные функции

| Функция | Описание |
|---|---|
| `get_prompt()` | Формирует приглашение к вводу на основе имени пользователя и компьютера |
| `expand_variables()` | Раскрывает переменные окружения вида `$NAME` |
| `execute_command()` | Разбирает введённую строку и обрабатывает команды |
| `main()` | Запускает интерактивный цикл ввода команд |

### Поддерживаемые команды

| Команда | Описание |
|---|---|
| `ls` | Выводит имя команды и переданные аргументы |
| `cd` | Выводит имя команды и переданные аргументы |
| `exit` | Завершает работу эмулятора |

На первом этапе команды `ls` и `cd` являются заглушками. Работа с файловой системой будет реализована на следующих этапах.

Дополнительно предусмотрены обработка неизвестных команд, проверка аргументов команды `exit` и поддержка пустого ввода.

### Настройки

На первом этапе отдельный конфигурационный файл и параметры командной строки не предусмотрены.

Имя пользователя, имя компьютера и переменные окружения получаются из текущей операционной системы.

## 4. Запуск программы

Для работы требуется установленный Python 3.

Дополнительные библиотеки не требуются.

### Запуск через командную строку

Из корневой папки проекта выполнить:

```bash
py src/main.py
```

### Запуск через IDLE

1. Открыть файл `src/main.py` в IDLE.
2. Выбрать `Run → Run Module`.
3. Ввести команды в открывшемся окне IDLE Shell.

### Запуск через run.bat

В Windows можно запустить файл `run.bat` из корневой папки проекта при условии, что команда `python` доступна в PATH.

## 5. Запуск тестов

Для автоматического тестирования используется стандартный модуль Python `unittest`.

Из корневой папки проекта выполнить:

```bash
py -m unittest discover -s tests -v
```

Тесты предназначены для проверки обработки команд `ls`, `cd`, `exit`, неизвестных команд, переменных окружения и пустого ввода.

## 6. Примеры использования

Пример работы эмулятора:

```text
user@hostname:~$ ls
ls: аргументы = []

user@hostname:~$ ls folder1 folder2
ls: аргументы = ['folder1', 'folder2']

user@hostname:~$ cd documents
cd: аргументы = ['documents']

user@hostname:~$ hello
hello: команда не найдена

user@hostname:~$ exit wrong
exit: неверные аргументы

user@hostname:~$ exit
```

При запуске имена пользователя и компьютера подставляются автоматически.

Пример раскрытия переменной окружения Windows:

```text
user@hostname:~$ ls $USERNAME
ls: аргументы = ['user']
```

Значение переменной зависит от настроек операционной системы.

## 7. Этапы разработки

- **Этап 1. REPL** — консольный интерфейс, обработка команд и переменных окружения.
- **Этап 2. Конфигурация** — параметры запуска и конфигурационный файл JSON.
- **Этап 3. VFS** — виртуальная файловая система.
- **Этап 4. Основные команды** — реализация команд `ls`, `cd`, `clear`, `uname`, `tree`.
- **Этап 5. Дополнительные команды** — реализация `touch` и `rm`.

Работа выполняется последовательно, с сохранением изменений в истории Git-коммитов.

## 8. Этап 2 — Конфигурация

На втором этапе реализована поддержка параметров командной
строки, JSON-конфигурации и автоматического выполнения
стартовых скриптов.

### Параметры командной строки

| Параметр | Назначение |
|---|---|
| `--vfs` | Путь к виртуальной файловой системе |
| `--startup-script` | Путь к стартовому скрипту |
| `--config` | Путь к конфигурационному JSON-файлу |

Пример запуска с параметрами:

```bash
py src/main.py --vfs data/vfs --startup-script scripts/startup.txt
```

Пример запуска с конфигурационным файлом:

```bash
py src/main.py --config config.json
```

### Конфигурационный файл

Файл `config.json` содержит параметры:

- `vfs_path` — путь к виртуальной файловой системе.
- `startup_script` — путь к стартовому скрипту.

Пример содержимого:

```json
{
  "vfs_path": "data/vfs",
  "startup_script": "scripts/startup.txt"
}
```

Значения из JSON-файла имеют приоритет над соответствующими
параметрами командной строки.

На втором этапе путь к VFS принимается как настройка,
но сама виртуальная файловая система ещё не загружается.

### Стартовые скрипты

Стартовый скрипт содержит команды эмулятора,
по одной в каждой строке.

При выполнении отображаются введённые команды
и результаты их обработки.

При обнаружении неизвестной команды или неверных
аргументов выполнение скрипта прекращается.

Команда `exit` штатно завершает работу эмулятора.

### Функции второго этапа

| Функция | Описание |
|---|---|
| `process_command()` | Обработка команды с возвратом статусов |
| `parse_arguments()` | Чтение параметров запуска |
| `load_config()` | Загрузка конфигурации из JSON |
| `get_settings()` | Применение приоритета настроек |
| `print_settings()` | Отладочный вывод настроек |
| `run_startup_script()` | Выполнение стартового скрипта |
| `interactive_mode()` | Интерактивный режим эмулятора |

Доработанные функции первого этапа:

- `execute_command()` — использует новую обработку команд.
- `main()` — поддерживает конфигурацию и стартовые скрипты.

### Скрипты проверки

Для тестирования второго этапа созданы BAT-скрипты:

| Файл | Назначение |
|---|---|
| `scripts/test_cli.bat` | Проверка аргументов командной строки |
| `scripts/test_config.bat` | Проверка приоритета JSON |
| `scripts/test_error.bat` | Проверка остановки при ошибке |

### Автоматическое тестирование

Для запуска всех тестов из корневой папки проекта
используется команда:

```bash
py -m unittest discover -s tests -v
```

Тестовый набор содержит:

- 7 тестов первого этапа.
- 6 тестов второго этапа.

Всего — 13 автоматических проверок.

### Примеры использования

Запуск с настройками из JSON:

```bash
py src/main.py --config config.json
```

Запуск с указанием стартового скрипта:
